0.6.0 — Apps tab source ready app catalog

  • Apps header tab (between Files and Settings); L1/R1 includes it.
  • Screen loads apps.json from the catalog host (VLC, Alembic, Playden + Prospero icons).
  • Always-latest download: Cross queries GitHub releases API and picks the matching zip (prereleases allowed for Playden).
  • Version string 0.6.0 in native/version.js.

Binary not produced in the cloud build environment. Run game-store/scripts/build.sh on the machine that has ps5-react + payload SDK + LLVM.

0.5.7 — catalog host move live catalog app

  • Catalog moved off GitHub Pages to a Vercel static host on the project domain so the console can reach the feed without a VPN in regions where github.io is blocked.
  • REMOTE_BASE in the app points at the new host (XOR-packed string in native/state/catalog.js).
  • Art URLs in games.json use absolute paths on the catalog host so the image disk cache keeps stable keys.
  • HTTP cache headers: covers long-lived immutable; games.json ~5 minutes.

Catalog pipeline catalog
