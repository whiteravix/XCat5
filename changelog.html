Moderate detail on catalog and app changes. Updated as work lands.

0.5.7 — catalog host move live catalog app

  • Catalog moved off GitHub Pages to a Vercel static host on the project domain so the console can reach the feed without a VPN in regions where github.io is blocked.
  • REMOTE_BASE in the app points at the new host (XOR-packed string in native/state/catalog.js). Version string set to 0.5.7.
  • Art URLs in games.json use absolute paths on the catalog host (…/covers/, …/heroes/, …/logos/) so the image disk cache keeps stable keys.
  • HTTP cache headers: covers/heroes/logos get long-lived immutable cache; games.json ~5 minutes; page/release JSON ~1 hour.
  • Test update: catalog host shape assertion no longer requires a github.io URL.

A patched 0.5.6 image was also produced earlier by binary-editing REMOTE_BASE only, for testing before a full 0.5.7 rebuild.

Catalog pipeline catalog

  • Public catalog repo remains the source of games.json, covers, release and page JSON.
  • Vercel project deploys that repo as a static site (no framework build).
  • Workflow can rewrite art URLs when the host changes (GitHub Actions on the catalog repo).

Source layout (build machine) app

  • game-store/ — console app (native/, scripts, version).
  • ps5-react/ — engine.
  • overdrive-catalog/ — private catalog used at build time for embeds/audits.
  • Build: game-store/scripts/build.sh → exFAT under 04_Releases/builds/.
